# Privacy Policy

_Last updated: 2026-11-19_

This application is a personal OAuth client used by its owner to access their
own Google Drive via rclone. It is not offered to the public.

## Data accessed and use

The application accesses Google Drive files of the owner's account only to
perform backup and synchronization requested by the owner.

## Storage and sharing

Data is processed on the owner's own devices. It is not collected by any server,
sold, shared with or disclosed to third parties, and not used for advertising or
for training AI/ML models.

## Google API Services User Data Policy

Use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at <https://myaccount.google.com/permissions>.
